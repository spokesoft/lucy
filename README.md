# 🐈‍⬛ Lucy

[![Build Status](https://img.shields.io/github/actions/workflow/status/spokesoft/lucy/build.yml?branch=master)](https://github.com/spokesoft/lucy/actions)
[![NuGet version](https://img.shields.io/nuget/v/Spokesoft.Lucy.svg)](https://www.nuget.org/packages/Spokesoft.Lucy/)
[![GitHub license](https://img.shields.io/github/license/spokesoft/lucy)](LICENSE)

Lucy is a .NET tool designed to streamline your project management directly from the command line. It helps you manage development tickets, sprints, and project backlogs with ease.

> For more detailed documentation, visit our **[GitHub Pages site](https://spokesoft.github.io/lucy/)**.

## Installation

To install Lucy, you'll need the .NET SDK. You can then install it as a global tool:

```bash
dotnet tool install --global Spokesoft.Lucy
```
